# Dados externos

Esta pasta permanece vazia no repositório público. Defina `AITHERMO_DATA_ROOT`
para apontar para uma cópia local dos dados obtidos com as estratégias de busca
e para os formulários humanos previstos nos contratos em `modelos/`.

Nenhum registro bibliográfico, artigo, planilha preenchida ou decisão científica
é distribuído neste repositório.
